Vous gardez le contrôle

Le profil peut afficher votre Riot ID, votre rang dans la file choisie, jusqu’à 10 parties classées récentes et, si Riot le signale, votre présence en partie, le champion et l’heure de début. Les statistiques détaillées d’une partie en cours ne sont pas disponibles via ces API.

Le service n’active que les plateformes dont les routes Riot nécessaires sont documentées et vérifiées.

Vous pourrez retirer cette autorisation ici à tout moment. Le service supprimera alors l’association et désactivera l’ancien lien ; les copies déjà enregistrées par un tiers ne peuvent pas être rappelées. Aucune donnée des autres participants n’est publiée.

Profil connecté
